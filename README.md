# Cat Facts Generator

A simple JavaScript project that fetches random cat facts using the Cat Facts API and displays them on the webpage.

## Features

* Fetches a random cat fact on button click
* Uses Axios for API requests
* Uses Async/Await for handling asynchronous operations
* Basic error handling for failed requests

## Technologies Used

* HTML
* JavaScript
* Axios
* Cat Facts API

## Purpose

This project was built to practice working with APIs, Axios, Async/Await, DOM manipulation, and error handling in JavaScript.
